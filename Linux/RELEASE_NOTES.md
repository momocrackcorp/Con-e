# Con-E Linux v0.1.0 — prueba para Ubuntu / Linux Mint

Primera versión nativa de diagnóstico de hardware: CPU, RAM, GPU, discos y USB, sensores, placa y firmware, red, audio, inventario PCI/USB, informe JSON y Acerca de con Coné.

- Diseño claro con tarjetas, miniaturas de almacenamiento y anillo de uso.
- Detalle de volúmenes y análisis cancelable de carpetas de la raíz.
- Lectura ampliada de módulos RAM y SMART mediante autorización explícita y comandos de sólo lectura.
- No incorpora WinPart, actualizaciones de programas ni gestión de controladores.

**Arquitectura:** x86-64 (amd64). Objetivo: Ubuntu 22.04/24.04 y Mint 21/22. La prueba en el hardware y escritorio Mint del usuario queda pendiente.
**Descarga sencilla:** con-e-linux_0.1.0_amd64.deb.
**Portátil:** Con-E-Linux-v0.1.0-x86_64.tar.gz; extrae todo y abre Iniciar-Con-E.sh.

No disponible significa que faltó una lectura; no se inventan sensores, módulos, salud ni fechas. Los porcentajes del análisis son sobre lo leído. Conserva el directorio _internal.
Incluye fuente, requisitos, avisos de terceros y sumas SHA-256. Capturas de documentación con datos simulados.
