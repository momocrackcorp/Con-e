# Almacenamiento compartido

PhysicalStorage.cs y DiskMiniature.cs: código propio del proyecto, MIT. La consulta es de sólo lectura; no es un motor de particiones.

disk-miniatures.png: atlas RGBA 2×2 de miniaturas ilustrativas aprobado por el usuario, creado con generación de imágenes y editado para quitar fondo y leyendas. Orden: HDD, SSD, M.2 SATA, M.2 NVMe. No contiene marcas de fabricantes. Se incluye como recurso incrustado en ambas aplicaciones y como fuente de recursos en WinPart.

Las formas son orientativas. El medio, la conexión y la presencia explícita de M.2 en el modelo se informan por separado. No se deduce M.2 a partir de NVMe. La imagen original de propuesta se conserva fuera del recurso de producción.

usb-miniature.png: miniatura RGBA genérica de pendrive sin marca, creada mediante generación de imágenes en el mismo estilo del atlas. Recurso UsbMiniature compartido por Con-E y WinPart; funciona sin conexión.
